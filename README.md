# 드래곤소드 카메라 · 키보드 메뉴 모드

드래곤소드: 어웨이크닝의 카메라 회전 딜레이를 없애고, 게임 메뉴를 키보드로 조작할 수 있게 합니다. **카메라 기능과 키보드 메뉴 기능은 각각 설치·삭제할 수 있습니다.**

**[설치·삭제 프로그램 다운로드](https://github.com/Zero-sugars/DragonSwordCameraNoDelay/releases/latest/download/DragonSword.CameraNoDelay.Setup.exe)** · [ZIP·이전 버전](https://github.com/Zero-sugars/DragonSwordCameraNoDelay/releases)

Windows 10/11 64비트용입니다. Steam판 1.1.2에서 확인했으며, 별도 프로그램 설치가 필요하지 않습니다.

## 설치

1. 게임을 완전히 종료합니다.
2. 내려받은 `DragonSword.CameraNoDelay.Setup.exe`를 실행합니다.
3. 자동 검색된 게임 폴더를 확인합니다. 찾지 못했다면 **폴더 선택**으로 `DSClient.exe`가 있는 폴더를 고릅니다.
4. 원하는 기능 행의 **설치 / 업데이트**를 누릅니다. 둘 다 사용하려면 **두 기능 모두 설치 / 업데이트**를 누르세요.
5. ‘설치됨’을 확인하고 Steam에서 게임을 실행합니다.

## 사용

게임을 실행하면 설치한 기능이 자동으로 적용됩니다. 타이틀 메뉴와 게임 안에서 연 메인 메뉴도 키보드로 조작할 수 있습니다.

| 키 | 동작 |
| --- | --- |
| WASD | 열린 메뉴의 항목 이동 |
| 스페이스바 | 선택·확인 |
| F | 던전 진입·팀 선택 화면에서 도전 / 던전 퇴장 승인 / 지도에서 워프 |
| Q / E | 첫 번째 탭 묶음의 이전 / 다음 탭 |
| 1 / 3 | 두 번째 탭 묶음의 이전 / 다음 탭 |
| F7 | 키보드 메뉴 조작 켜기·끄기 |
| F8 | 카메라 딜레이 제거 켜기·끄기 |

게임 내 아이콘 메인 메뉴에서는 마우스를 올린 항목으로 키보드 선택도 이동합니다. 마우스가 아이콘 밖으로 나가도 마지막 키보드 선택 표시가 유지됩니다. 그 항목에서 WASD로 이어서 이동하거나 Space로 실행할 수 있습니다. 마우스를 가만히 두면 WASD로 옮긴 선택을 유지합니다.

모든 메뉴에서 **X 닫기 버튼은 WASD·Space 선택 대상에서 제외**합니다. 메뉴의 ‘종료’ 항목과 글자로 표시된 ‘닫기’ 동작은 사용할 수 있으며, Esc는 게임의 기존 기능을 사용합니다.

메뉴를 닫으면 기존 이동·점프·스킬 조작을 사용합니다. 채팅·검색창 입력 중에는 메뉴 단축키가 작동하지 않습니다. 목록 스크롤·슬라이더는 마우스를 사용하세요. 켜짐·꺼짐 알림은 따로 표시되지 않습니다.

장비 화면의 왼쪽 메뉴처럼 첫 번째 탭은 **Q/E**, 투구·상의·하의 같은 두 번째 탭은 키보드 윗줄의 **1/3**으로 전환합니다. 양 끝에서는 순환합니다. 세 번째 이하의 탭은 단축키와 WASD 선택 대상에서 제외하며, 필요하면 마우스로 조작하세요.

확인 팝업은 활성화된 버튼이 **1개면 Space로 바로 실행**, **2개면 취소 반대편 버튼을 Space로 실행**합니다. **3개 이상일 때만 A/D로 버튼을 고른 뒤 Space로 실행**합니다. Esc 취소는 게임의 기존 기능을 사용합니다. 창 테두리의 닫기 버튼은 선택지 수에서 제외합니다. 두 버튼 중 확인·취소를 구분하지 못하면 임의로 실행하지 않습니다.

‘제단에서 나가기’ 같은 **던전 퇴장 동작과 확인창은 F로 승인**합니다. 해당 버튼에는 `F`가 표시되며 Space로 퇴장을 승인하지 않습니다. Esc 취소와 일반 확인창의 Space 동작은 유지됩니다.

아이템 사용 뒤 잠깐 표시되는 알림은 아이템창의 키보드 조작을 막지 않습니다. 퀵슬롯 등록창은 WASD로 슬롯을 고르고 Space로 선택합니다. 이어서 등록 버튼이 선택되면 Space를 한 번 더 눌러 등록합니다. Esc로 취소하거나 마우스로 창을 닫은 뒤에도 아이템창을 계속 조작할 수 있습니다.

크게 열린 지도 화면에서는 **WASD로 지도 이동**, **Q로 축소**, **E로 확대**합니다. 키를 누르고 있으면 프레임에 맞춰 부드럽게 이동하고, 놓으면 멈춥니다. **F는 오른쪽 정보창에 ‘워프’ 또는 ‘근처로 워프’ 버튼이 보이고 활성화됐을 때만** 작동합니다. 지도에서 스페이스바는 동작하지 않습니다. 평소 HUD의 작은 미니맵에는 이 조작을 적용하지 않습니다.

용의 제단 같은 던전 진입 화면과 그다음 팀 선택 화면에서는 **F로 ‘도전’ 버튼을 바로 실행**합니다. 해당 버튼이 보이고 활성화됐을 때만 작동하며, 다른 팝업이 앞에 열렸을 때는 뒤쪽 도전을 실행하지 않습니다. 일반 팀 편성 화면의 ‘편성 완료’ 버튼에는 F를 연결하지 않습니다.

고정 단축키가 있는 버튼 오른쪽에는 작은 키 표시가 붙습니다. 첫 번째·두 번째 탭은 현재 탭 오른쪽에 `Q/E`, `1/3`을 표시합니다. 지도는 `Q/E/F`, 던전의 도전 버튼은 `F`, 소형 팝업의 확인 버튼은 `Space`로 표시합니다. F7로 메뉴 기능을 끄면 이 표시도 사라집니다. 팝업이 앞에 열리면 뒤의 지도·메뉴에 입력을 전달하지 않습니다.

## 삭제

게임을 종료한 뒤 같은 프로그램에서 지울 기능 행의 **삭제**를 누릅니다. 다른 기능은 유지됩니다. 둘 다 지우려면 **전체 삭제**를 누르세요. 마지막 기능을 삭제하면 공용 파일도 함께 제거됩니다.

삭제한 모드 파일은 게임 폴더의 `DS\Binaries\Win64\CameraNoDelay-backup-*`에 보관됩니다. 세이브 파일은 변경하지 않습니다.

## 업데이트

기존 설치 프로그램을 닫고 최신 파일을 받으세요. 게임을 종료한 상태에서 원하는 기능의 **설치 / 업데이트**를 누르면 됩니다. 이전 버전으로 자동 설치한 모드도 인식합니다.

## 문제가 있을 때

- 게임을 종료했는데 버튼이 비활성화되어 있으면 **상태 새로고침**을 누르세요.
- 설치 파일이 누락됐다면 해당 기능의 **설치 / 업데이트**로 복구할 수 있습니다.
- 다른 UE4SS 모드를 사용 중이라면 [수동 설치 안내](docs/MANUAL-INSTALL.md)를 확인하세요.
- 문제가 계속되면 게임 버전과 증상을 적어 [문제를 알려주세요](https://github.com/Zero-sugars/DragonSwordCameraNoDelay/issues).

게임 업데이트 후에는 동작이 달라질 수 있습니다. 게임 제작사와 무관한 비공식 모드입니다.
