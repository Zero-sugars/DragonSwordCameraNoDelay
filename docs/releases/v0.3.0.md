키보드 메뉴 조작 기능을 추가했습니다.

- WASD: 열린 메뉴의 항목 이동
- 스페이스바: 선택·확인
- Q / E: 이전·다음 탭 전환
- F7: 메뉴 조작 기능 켜기·끄기
- F8: 카메라 딜레이 제거 켜기·끄기

게임을 완전히 종료한 뒤 **DragonSword.CameraNoDelay.Setup.exe**를 실행하고 **모드 설치 / 업데이트**를 누르세요. 이전 버전에서 그대로 업데이트할 수 있습니다.

타이틀·설정·인벤토리에서 확인했습니다. 드래그가 필요한 슬라이더·지도와 목록 스크롤은 마우스를 사용하세요. 모든 메뉴와 캐릭터 조합을 확인한 것은 아닙니다.

다른 UE4SS 모드와 함께 쓰는 경우에는 `mod-only.zip`과 [수동 설치 안내](https://github.com/Zero-sugars/DragonSwordCameraNoDelay/blob/main/docs/MANUAL-INSTALL.md)를 이용하세요.
