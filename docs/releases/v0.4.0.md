카메라 회전 딜레이 제거와 키보드 메뉴 조작을 함께 제공하는 공개 배포판입니다.

- **기능별 설치·삭제**: 키보드 메뉴 조작과 카메라 딜레이 제거 중 필요한 기능만 설치할 수 있습니다.
- **메뉴·아이템창**: WASD 이동, Space 선택·확인, Q/E 첫 번째 탭 전환, 1/3 두 번째 탭 전환을 지원합니다. X 닫기 버튼은 선택 대상에서 건너뜁니다.
- **마우스 연동**: 게임 내 아이콘 메인 메뉴에서 마우스를 올린 항목으로 키보드 선택도 옮겨집니다. 마우스가 벗어나도 선택 표시는 유지됩니다.
- **지도**: WASD로 부드럽게 이동하고 Q/E로 축소·확대합니다. 활성화된 ‘워프’·‘근처로 워프’ 버튼은 F로 실행합니다.
- **던전**: 진입·팀 선택의 ‘도전’과 던전 퇴장 승인은 F로 실행합니다. 퇴장 확인창에서는 Space로 승인하지 않습니다.
- **확인창**: 버튼 1개는 Space로 실행, 2개는 취소 반대편 버튼을 Space로 실행합니다. 3개 이상일 때만 A/D로 고릅니다. Esc 취소는 게임의 기존 기능을 사용합니다.
- 아이템 사용·등록 후 키보드 조작이 멈추던 문제, 전투 중 Space로 가방이 열리던 문제, 지도 이동 입력이 간헐적으로 누락되던 문제를 수정했습니다.

## 다운로드·설치

1. 아래 **Assets**에서 **DragonSword.CameraNoDelay.Setup.exe**를 받습니다.
2. 게임과 기존 설치 프로그램을 완전히 종료한 뒤 새 설치 프로그램을 실행합니다.
3. 자동으로 찾은 게임 폴더를 확인합니다. 찾지 못하면 **폴더 선택**으로 `DSClient.exe`가 있는 폴더를 지정하세요.
4. 원하는 기능 행의 **설치 / 업데이트**를 누릅니다. 둘 다 사용하려면 **두 기능 모두 설치 / 업데이트**를 누르세요.
5. Steam에서 게임을 실행합니다.

기존 버전 사용자도 새 설치 프로그램에서 업데이트할 수 있습니다. 삭제는 게임 종료 후 같은 프로그램에서 해당 기능의 **삭제** 또는 **전체 삭제**를 누르세요.

게임에서 **F7**은 키보드 메뉴 조작, **F8**은 카메라 딜레이 제거를 켜거나 끕니다. 고정 단축키는 해당 버튼 오른쪽에 작게 표시됩니다.

Windows 10/11 64비트용이며, Steam판 1.1.2에서 확인했습니다. 별도 프로그램 설치는 필요하지 않습니다. 다른 UE4SS 모드를 사용 중이라면 [수동 설치 안내](https://github.com/Zero-sugars/DragonSwordCameraNoDelay/blob/main/docs/MANUAL-INSTALL.md)를 확인하세요.
