드래곤소드: 어웨이크닝에서 마우스를 움직일 때 카메라가 늦게 따라오는 회전 보간을 끄는 첫 배포 버전입니다.

## 설치

1. 게임을 완전히 종료합니다.
2. 아래 Assets에서 **`DragonSwordCameraNoDelay-v0.1.0.zip`**을 받습니다.
3. ZIP을 새 폴더에 모두 압축 해제하고 **`Install.cmd`**를 실행합니다.
4. Steam에서 게임을 실행합니다. 모드는 기본으로 켜집니다.

**F8**로 켜기·끄기를 비교할 수 있습니다. 제거하려면 게임을 종료하고 배포 폴더의 **`Remove.cmd`**를 실행하세요.

기존 UE4SS를 사용하는 경우와 경로 자동 검색에 실패한 경우는 [설치 안내](https://github.com/pwj891129-arch/DragonSwordCameraNoDelay#설치-방법)를 참고하세요. `Source code` 파일은 개발용 소스입니다.

## 확인한 환경

- Steam 게임 1.1.2, 앱 4570720 / 빌드 26210326, Unreal Engine 5.3.
- 실제 게임 적용·F8 복원과 사용자 체감 테스트를 확인했습니다.
- 자동 설치·제거·재설치 및 Lua 동작 테스트를 통과했습니다.
- 모든 캐릭터·탑승·컷신·협동 플레이 조합은 검증하지 않았습니다.

UE4SS 로더와 라이선스를 포함하므로 별도 로더 다운로드 없이 설치할 수 있습니다. 원본 실행 파일·PAK·게임 설정·세이브를 패치하지 않습니다.

SHA256은 함께 첨부한 `SHA256SUMS.txt`에서 확인할 수 있습니다.
