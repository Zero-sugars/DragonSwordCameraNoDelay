설치·삭제 버튼이 있는 한국어 프로그램을 추가했습니다.

## 사용 방법

1. 게임을 완전히 종료합니다.
2. 아래 Assets에서 **`DragonSword.CameraNoDelay.Setup.exe`**를 받습니다. 전체 ZIP으로 받았다면 먼저 압축을 풉니다.
3. 프로그램을 실행하고 자동 검색된 게임 폴더를 확인합니다. 필요하면 **폴더 선택**으로 지정합니다.
4. **모드 설치 / 업데이트**를 누릅니다. 삭제할 때는 같은 프로그램에서 **모드 삭제**를 누르세요.

0.1.0의 자동 설치로 설치한 모드도 업데이트·삭제할 수 있습니다. 필요한 .NET 런타임과 모드 자료가 포함되어 있어 별도 설치나 로더 다운로드가 필요하지 않습니다. Windows 10/11 64비트용입니다.

## 변경 사항

- 게임 폴더 자동 검색·직접 선택과 설치 상태 표시.
- 설치·업데이트·삭제 버튼 및 한국어 처리 결과.
- 게임 실행 중 파일 작업 차단.
- 누락된 설치 파일 복구와 누락 파일이 있는 상태에서의 삭제 지원.
- 설치·삭제가 파일 잠금으로 실패하면 완료된 파일 작업을 되돌림.
- 변경된 파일, 다른 UE4SS 모드, 잘못된 설치 기록 보호.

삭제한 파일은 게임 폴더의 `DS\Binaries\Win64\CameraNoDelay-backup-*`에 보관합니다. 기존 UE4SS에 수동 설치한 경우는 [설치 안내](https://github.com/pwj891129-arch/DragonSwordCameraNoDelay#이미-ue4ss를-설치한-경우)를 확인하세요.

카메라 Lua 모드는 0.1.0과 동일하며 F8로 켜기·끄기를 전환할 수 있습니다. 확인한 게임 버전은 Steam 1.1.2 / 빌드 26210326입니다.

SHA256은 `SHA256SUMS-v0.2.0.txt`에 첨부합니다.
