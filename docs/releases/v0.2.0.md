## 사용 방법

1. 게임을 종료하고 아래 **Assets**의 `DragonSword.CameraNoDelay.Setup.exe`를 실행합니다.
2. 게임 폴더를 확인한 뒤 **모드 설치 / 업데이트**를 누릅니다.
3. 삭제할 때는 같은 프로그램에서 **모드 삭제**를 누릅니다.

게임에서 **F8**로 모드를 켜거나 끌 수 있습니다. Windows 10/11 64비트용입니다.
