설치 창을 가만히 두어도 6초마다 새로고침되던 동작을 수정했습니다.

## 수정 내용

- 주기적인 설치 상태 확인 타이머를 제거했습니다.
- 아무 작업도 하지 않을 때 입력창·버튼이 잠깐 비활성화되거나 대기 커서가 나타나지 않습니다.
- 시작 시, 게임 폴더를 바꿀 때, 설치·삭제 후에는 상태를 확인합니다.
- 상태를 다시 확인하려면 **상태 새로고침** 버튼을 누르세요. 게임을 종료한 뒤에도 이 버튼으로 설치·삭제 버튼을 갱신할 수 있습니다.

기존 설치 프로그램을 닫고 새 **`DragonSword.CameraNoDelay.Setup.exe`**를 실행하세요. 카메라 모드를 다시 설치할 필요는 없습니다.

기존 0.1.0·0.2.0 설치본의 업데이트·삭제를 지원합니다. 별도 .NET 설치는 필요하지 않으며 Windows 10/11 64비트용입니다.

기존 새로고침 주기 두 번보다 긴 13초 동안 추가 상태 조회·입력 상태 변경이 없는지 확인하고, 수동 새로고침과 설치·삭제 버튼을 테스트했습니다. SHA256은 `SHA256SUMS-v0.2.1.txt`에 첨부합니다.
