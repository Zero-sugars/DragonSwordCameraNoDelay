설치 창을 열어둔 상태에서 입력창과 버튼이 주기적으로 깜빡이던 문제를 수정했습니다.

## 다운로드·설치

1. 아래 **Assets**에서 `DragonSword.CameraNoDelay.Setup.exe`를 받습니다.
2. 게임을 종료하고 프로그램을 실행합니다.
3. 게임 폴더를 확인한 뒤 **모드 설치 / 업데이트**를 누릅니다.

삭제할 때는 같은 프로그램에서 **모드 삭제**를 누르세요. Windows 10/11 64비트용이며, 별도 프로그램 설치는 필요하지 않습니다.

기존 모드를 사용 중이라면 설치 창을 닫고 새 실행 파일로 교체하면 됩니다. 이번 수정 때문에 모드를 다시 설치할 필요는 없습니다. 게임 종료 후 버튼이 비활성화되어 있으면 **상태 새로고침**을 누르세요.

게임에서 **F8**로 모드를 켜거나 끌 수 있습니다.
