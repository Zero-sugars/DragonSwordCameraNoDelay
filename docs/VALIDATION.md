# 검증 범위

## 설치·삭제 프로그램 0.2.0

같은 내장 설치 도구를 사용하는 실행 파일에서 새 설치·삭제·재설치, 기존 0.1.0 업데이트, 한글·공백·특수 문자가 있는 경로, 누락 파일 복구·삭제를 검사합니다. 파일 잠금으로 설치와 삭제를 실패시킨 뒤 이전 파일과 설치 기록이 복원되는지도 검사합니다.

변경된 파일, 다른 UE4SS 모드, 허용되지 않은 설치 기록의 경로가 있을 때 작업을 중단하고 원본 게임 파일과 무관한 파일을 보존하는지 검사합니다.

위 실행 파일 테스트를 통과했습니다. 별도의 테스트 게임 폴더에서 설치·삭제 버튼 이벤트와 상태 전환을 실행했으며, 설치·삭제 후 화면을 렌더링해 한글·버튼·결과 표시의 배치를 확인했습니다. 외부 화면 자동화 도구는 창 식별 오류로 연결하지 못해 이 UI 테스트로 검증했습니다.

최종 독립 실행 파일은 `DOTNET_ROOT`와 `DOTNET_ROOT_X64`를 빈 폴더로 지정한 상태에서도 위 테스트를 통과했습니다. 배포 ZIP의 CRC, ZIP 내부와 별도 배포 실행 파일의 SHA256 일치, 라이선스 포함 여부를 확인했습니다. 빌드 시 원격 NuGet 취약성 정보 조회는 NU1900 경고로 완료되지 않았습니다.

아래 실제 게임 검증은 동일한 카메라 Lua 모드 0.1.0에 대한 기록입니다.

## 카메라 Lua 모드 0.1.0

검증일: 2026-10-31. 대상은 Steam 앱 4570720, 빌드 26210326, 게임 1.1.2입니다.

## 실제 게임에서 확인

- UE4SS가 Unreal Engine 5.3을 인식하고 Lua 모드를 로드했습니다.
- 로컬 플레이어 카메라에서 회전 지연이 켜져 있고 속도가 10인 것을 확인했습니다.
- 모드가 회전 지연을 끄고 속도를 0으로 설정한 뒤, 두 값을 다시 읽어 적용 여부를 확인했습니다.
- F8을 여러 차례 눌러 원래 값 복원과 재적용 로그를 확인했습니다.
- 사용자가 게임에서 마우스 회전 딜레이가 없어졌음을 확인했습니다.
- 설치한 파일 7개의 SHA256이 배포본과 일치하며, 원본 게임 실행 파일의 SHA256은 변경되지 않았습니다.

## 자동 테스트

- 카메라 값 적용·복원, 게임이 이후 바꾼 값 보존, 무효화된 객체 처리.
- 로컬 플레이어에만 적용, 원격 플레이어 제외, 캐릭터 교체 시 적용, F8 토글, F9 상태 출력.
- 위치 보간과 충돌 속성 보존.
- 설치·백업 제거·재설치, 외부에서 수정된 파일 처리, 무관한 파일 보존.
- 설치 프로그램을 PowerShell 7과 Windows PowerShell 5.1에서 실행.
- 배포 ZIP CRC와 내부 파일 SHA256 검증.

## 추가 확인이 필요한 범위

모든 캐릭터·탑승·컷신·협동 플레이 조합을 실제 게임에서 검증한 것은 아닙니다. 캐릭터 교체에 대한 자동 테스트는 실제 게임의 모든 전환 상황을 보장하지 않습니다. 게임 업데이트 후에는 로더와 카메라 구조의 호환성을 다시 확인해야 합니다.
