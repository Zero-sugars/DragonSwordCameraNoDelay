드래곤소드 모드 v0.4.0

Windows 10/11 64비트용. Steam판 1.1.2에서 확인했습니다.
별도 프로그램 설치가 필요하지 않습니다.

설치
1. 게임을 완전히 종료합니다.
2. DragonSword.CameraNoDelay.Setup.exe를 실행합니다.
3. 게임 폴더를 확인합니다. 찾지 못했다면 [폴더 선택]으로
   DSClient.exe가 있는 폴더를 고릅니다.
4. 원하는 기능 행의 [설치 / 업데이트]를 누릅니다.
   둘 다 사용하려면 [두 기능 모두 설치 / 업데이트]를 누르세요.
5. [설치됨]을 확인하고 Steam에서 게임을 실행합니다.

사용
게임을 실행하면 설치한 기능이 자동으로 적용됩니다.
WASD: 열린 메뉴의 항목 이동(X 닫기 버튼은 건너뜁니다)
스페이스바: 선택·확인
게임 내 아이콘 메인 메뉴: 마우스를 올린 항목에서 WASD 이동·Space 실행을 이어갑니다.
마우스를 가만히 두면 WASD로 옮긴 선택이 유지됩니다.
마우스가 아이콘 밖으로 나가도 키보드 선택 표시는 유지됩니다.
F: 던전 진입·팀 선택 화면의 도전 / 던전 퇴장 승인(버튼 오른쪽에 F 표시)
Q / E: 첫 번째 탭의 이전 / 다음 전환
1 / 3: 두 번째 탭의 이전 / 다음 전환(키보드 윗줄 숫자)
세 번째 이하 탭은 키보드 조작에서 제외합니다. 필요하면 마우스를 사용하세요.
F7: 키보드 메뉴 조작 켜기·끄기
F8: 카메라 딜레이 제거 켜기·끄기
던전 퇴장 동작·확인창: F로 승인합니다. Space는 퇴장을 승인하지 않습니다.
일반 확인창: 버튼 1개는 Space로 바로 실행 / 2개는 취소 반대편 버튼을 Space로 실행
버튼 3개 이상일 때만 A/D로 선택 후 Space로 실행합니다. Esc 취소는 게임의 기존 기능입니다.
창 테두리의 닫기 버튼은 선택지 수에서 제외합니다.
퀵슬롯 등록: WASD로 슬롯 이동, Space로 선택 후 등록 버튼에서 Space로 등록합니다.
사용 알림이나 닫힌 팝업이 아이템창 키보드 조작을 막지 않도록 수정했습니다.
큰 지도: WASD 이동(누르는 동안 부드럽게 연속 이동), Q 축소, E 확대
F: 오른쪽 정보창에 활성화된 '워프' 또는 '근처로 워프' 버튼이 보일 때만 워프
지도에서 스페이스바는 아무 동작도 하지 않습니다.
고정 단축키는 버튼 오른쪽에 작은 Q/E, 1/3, F, Space로 표시합니다.
메뉴를 닫으면 기존 이동·점프·스킬 조작을 사용합니다.
채팅·검색창 입력 중에는 메뉴 단축키가 작동하지 않습니다.
목록 스크롤·슬라이더는 마우스를 사용하세요. 지도는 마우스 드래그도 함께 사용할 수 있습니다.
켜짐·꺼짐 알림은 따로 표시되지 않습니다.

삭제
게임을 종료한 뒤 같은 프로그램에서 지울 기능 행의 [삭제]를 누르세요.
다른 기능은 유지됩니다. 둘 다 지우려면 [전체 삭제]를 누르세요.
[설치되지 않음]으로 바뀌면 완료입니다.
모드 파일은 게임의 DS\Binaries\Win64\CameraNoDelay-backup-*에 보관됩니다.
세이브 파일은 변경하지 않습니다.

업데이트
기존 설치 프로그램을 닫고 최신 파일을 받으세요.
게임을 종료한 상태에서 원하는 기능의 [설치 / 업데이트]를 누르면 됩니다.

문제가 있을 때
게임 종료 후 버튼이 비활성화되어 있으면 [상태 새로고침]을 누르세요.
설치 파일이 누락됐다면 설치 버튼으로 복구할 수 있습니다.
다른 UE4SS 모드를 사용 중이라면 아래 페이지의 수동 설치 안내를 확인하세요.
