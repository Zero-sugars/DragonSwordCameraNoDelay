드래곤소드: 어웨이크닝 카메라 회전 딜레이 제거 모드 0.2.0

설치
1. 게임을 완전히 종료합니다.
2. DragonSword.CameraNoDelay.Setup.exe를 실행합니다.
3. 자동 검색된 게임 폴더를 확인합니다.
   찾지 못했다면 [폴더 선택]으로 DSClient.exe가 있는 폴더를 고르세요.
4. [모드 설치 / 업데이트]를 누릅니다.
5. [설치됨]을 확인하고 Steam에서 게임을 실행합니다.

삭제
게임을 종료한 뒤 같은 프로그램을 실행하고 [모드 삭제]를 누르세요.
[설치되지 않음]으로 바뀌면 완료입니다.
파일은 게임의 DS\Binaries\Win64\CameraNoDelay-backup-* 폴더에 보관합니다.

기존 0.1.0 자동 설치본도 인식해 업데이트하거나 삭제할 수 있습니다.
일부 파일이 누락됐다면 설치 버튼으로 복구할 수 있습니다.
게임 실행 중에는 설치·삭제 버튼을 사용할 수 없습니다.

F8: 카메라 딜레이 제거 켜기 / 끄기. 게임 실행 시 기본 켜짐.
F9: 카메라 상태를 ue4ss\UE4SS.log에 기록.

Windows 10/11 64비트용입니다.
.NET 런타임과 모드 자료를 포함해 별도 설치나 로더 다운로드가 필요하지 않습니다.
원본 EXE, PAK, 게임 설정, 세이브는 패치하지 않습니다.

기존에 다른 UE4SS 로더나 모드가 있거나 설치 파일을 직접 수정한 경우에는
자동 작업을 중단합니다. 프로그램의 안내와 아래 설치 문서를 확인하세요.

확인한 게임: Steam 1.1.2 / 앱 4570720 / 빌드 26210326 / UE 5.3.
카메라 Lua 모드는 0.1.0과 동일하며, 실제 게임에서 딜레이 제거를 확인했습니다.
탑승·컷신·협동 플레이의 모든 조합은 검증하지 않았습니다.
